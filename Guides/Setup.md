# Setup Guide

## Context

Forgebase itself is documentation-first, but it assumes you're working on a backend-enabled project. This guide helps you prepare your environment to use Forgebase effectively.

## When to Use This

- **Read if:** You're setting up a new project and want to use Forgebase
- **Reference if:** You're unclear on prerequisites or tooling
- **Skip if:** Your environment is already set up

---

## Prerequisites

- Basic backend understanding
- Familiarity with APIs & databases
- Git & GitHub basics

---

## Recommended Tooling

- Code editor (VS Code / JetBrains)
- Git
- Database client
- API testing tool (Postman / Hoppscotch)

---

## How to Use Forgebase Locally

1. Clone the Forgebase repository
2. Read the guides before writing code
3. Adapt patterns to your stack (Node, Go, Java, etc.)
4. Avoid copy-pasting blindly—understand decisions

---

## Mental Setup (Important)

Forgebase assumes:
- You prefer **clarity over speed**
- You want **long-term maintainability**
- You are willing to say “no” to unnecessary features
