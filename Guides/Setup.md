# Setup Guide

Forgebase itself is documentation-first, but it assumes you are working on a backend-enabled project.

This guide explains how to prepare your environment to **use Forgebase effectively**.

---

## Prerequisites

- Basic backend understanding
- Familiarity with APIs & databases
- Git & GitHub basics

---

## Recommended Tooling

- Code editor (VS Code / JetBrains)
- Git
- Database client
- API testing tool (Postman / Hoppscotch)

---

## How to Use Forgebase Locally

1. Clone the Forgebase repository
2. Read the guides before writing code
3. Adapt patterns to your stack (Node, Go, Java, etc.)
4. Avoid copy-pasting blindly—understand decisions

---

## Mental Setup (Important)

Forgebase assumes:
- You prefer **clarity over speed**
- You want **long-term maintainability**
- You are willing to say “no” to unnecessary features
