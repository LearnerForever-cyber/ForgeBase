# Executing Forgebase

## Context

Forgebase is not theoretical. This guide describes how to actually use Forgebase in your project, from learning to validation.

## When to Use This

- **Read if:** You want a step-by-step path to use Forgebase
- **Reference if:** You're uncertain about the order to learn or implement things
- **Skip if:** You already know where to start

## How to use
1. Read Philosophy
2. Understand Architecture
3. Copy Core contracts
4. Adapt Modules
5. Validate via real usage

If your backend survives real users, Forgebase worked.
