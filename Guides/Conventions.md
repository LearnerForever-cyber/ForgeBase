# Conventions

## Context

Consistency reduces cognitive load. This guide establishes naming, git, and structural conventions that Forgebase recommends.

## When to Use This

- **Read if:** You're starting a project and want to align with Forgebase conventions
- **Reference if:** You're uncertain about naming or structure decisions
- **Skip if:** Your project already has established conventions

---

## Naming

- Clear over clever
- Explicit over short
- Avoid abbreviations

---

## Git Practices

- Small commits
- Descriptive messages
- One logical change per commit

---

## Folder Structure

Structure should reflect **responsibility**, not tech.
