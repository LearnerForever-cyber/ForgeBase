# Operations

## Context

A system you can't observe is a system you can't trust. This guide explains operational practices for monitoring and maintaining Forgebase backends.

## When to Use This

- **Read if:** You're setting up monitoring and observability for your backend
- **Reference if:** You're designing logging or metrics strategy
- **Skip if:** You're not yet in production
