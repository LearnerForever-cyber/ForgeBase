# FORGEBASE

> Forgebase is a documentation platform and backend starter kit for students, entrepreneurs, and developers building serious projects who want to avoid the complexity of backend setup.  
> It provides ready-to-use backend modules that can be customized for any project.  
> The Forgebase docs are extracted from a platform called **EduBro**, which is being built by the founder of Forgebase.
