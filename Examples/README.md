# Examples

This folder contains **reference implementations** that demonstrate how
Forgebase modules are composed in real-world projects.

These examples focus on **architecture, contracts, and correctness** —
not frameworks or UI.

---

## What These Examples Show

- Correct module composition
- API boundary design
- Security-first defaults
- Realtime and offline patterns
- Failure-aware backend thinking

---

## What These Examples Do NOT Show

- UI or frontend code
- Framework-specific boilerplate
- Full production deployments
- Scaling optimizations

Use these examples as **blueprints**, not copy-paste templates.

---

## How to Use

- Start with `basic-backend/`
- Explore `realtime-example/` and `offline-first/` next
- Refer to `edubro-reference/` for real-world validation

Forgebase examples prioritize **clarity over completeness**.
> Forgebase patterns are validated in production via EduBro (see `examples/Backend-Reference.md`).
