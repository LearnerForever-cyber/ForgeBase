# Basic Backend Example

This example shows the **minimum correct backend structure**
built using Forgebase principles.

It represents a small but production-safe backend with:
- Authentication
- User ownership
- One core resource

---

## Included Modules

- Auth
- Users
- Notes (example resource)

---

## Key Ideas

- Clear separation of concerns
- Explicit API contracts
- Ownership enforced at data layer
- Security by default

This is the recommended starting point for new projects.
